## GAMEBOOST {{VERSION}}

需要 64 位 Windows 10 或 Windows 11。

1. 解压 `GAMEBOOST-{{VERSION}}-windows-x64.zip`，运行 `GAMEBOOST.exe`。
2. 在「节点配置」中导入节点 JSON 文件或 `mierus://` 分享链接。
3. 在「分流规则」中选择进程模式或 IP 模式，保存清单后点击「开始加速」。

「出口检测」通过当前节点访问 `https://ip.sb/`。SHA-256 校验值见发布包旁的 `.sha256` 和包内的 `SHA256SUMS.txt`。
