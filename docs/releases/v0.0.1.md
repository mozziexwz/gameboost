## GAMEBOOST v0.0.1

GAMEBOOST 是适用于 64 位 Windows 10 和 Windows 11 的 Mieru 游戏加速启动器。

- 支持按进程名、程序路径或文件夹分流，也支持按目标 IPv4、IPv6 或 CIDR 网段分流。
- 支持导入 Mieru JSON 配置和 `mierus://` 分享链接，并选择节点的 TCP 或 UDP 传输。
- 显示上下行速率、累计流量、出口 IPv4、节点入口延迟和出口 HTTPS 响应延迟。HTTPS 检测目标为 `https://ip.sb/`。
- 加速时经当前节点中继系统 DNS 查询。

解压 `GAMEBOOST-v0.0.1-windows-x64.zip`，运行 `GAMEBOOST.exe` 并授权管理员权限。导入节点配置，保存分流规则，然后开始加速。

发布包包含许可证、第三方组件版权声明和 SHA-256 校验值。
